# Pink Scientific Calculator

A baby pink themed desktop scientific calculator built with Core Java, Swing, and AWT featuring keyboard support and calculation history.

## Features
- **Arithmetic & Scientific Functions:** Supports `+`, `-`, `*`, `/`, `%`, `sin`, `cos`, `tan`, square root (`√`), square (`x²`), `log`, `1/x`, and constants (`π`, `e`).
- **Keyboard Support:** Full keyboard input support alongside GUI buttons (`KeyListener` & `ActionListener`).
- **Real-time Calculation History:** Displays a live history log with a one-click clear button.
- **Error Handling:** Safely handles division by zero and negative square roots.
